# PlatiNomNomHiDPI

HiDPI version of the [PlatiNomNom](https://github.com/moltensoftware/PlatiNomNom) xfce theme.

This version uses PNGs instead of XPMs, so it will probabily not work  with xfce <4.2.

## How to install

Copy PlatiNomNomHiDPI folder to ~/.local/share/themes to install, then select via the Window Manager app.

Icons in this screenshot are 'NineIcons' from Grassmunk https://github.com/grassmunk/Platinum9
